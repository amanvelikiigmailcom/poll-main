# Правила работы с проектом Flyprox

## Назначение и структура

Flyprox — локальная игра-викторина с игровыми именами участников. Основное приложение Flutter находится в `app/`. Серверной части в репозитории нет: игровое состояние хранится локально через `SharedPreferences` и `LocalGameService`.

- Точка входа: `app/lib/main.dart`, `app/lib/app.dart`.
- Маршруты: `app/lib/router/app_router.dart`.
- Логика локальной игры: `app/lib/services/local_game_service.dart`.
- Приглашения и отправка ссылок: `app/lib/services/invite_share_service.dart`.
- Основные экраны: `app/lib/screens/`.
- Flutter-пакет: `app/`. Имя пакета `flyprox_app` сохранять в `pubspec.yaml` и импортах.
- Подготовка облачной iOS-сборки: `app/ios/ci_scripts/ci_post_clone.sh`.

## Xcode Cloud

- Первое подключение каждого отдельного проекта к Xcode Cloud и его первую сборку настраивай через Xcode на Mac. Сама сборка выполняется в облаке Apple.
- После успешной первой сборки Xcode для этого проекта можно удалить. Последующие сборки и workflows доступны через App Store Connect; подключение GitHub продолжает запускать облачные сборки.
- Новые workflows уже подключённого проекта можно создавать через App Store Connect. Для отдельного нового проекта сначала требуется первичное подключение через Xcode; App Store Connect API управляет уже обнаруженными Xcode Cloud products и не заменяет первичную регистрацию проекта.
- Для этого Flutter-проекта Xcode Cloud использует `app/ios/ci_scripts/ci_post_clone.sh` для установки Flutter в облачной среде.
- App Store Connect API после одобрения доступа и создания ключа позволяет запускать сборки Xcode Cloud, управлять workflows, TestFlight, метаданными и отправкой версии на проверку. Оно не создаёт карточки приложений и не загружает бинарники напрямую; первое подключение проекта к Xcode Cloud всё равно выполняется через Xcode.
- Храни приватный API-ключ `.p8` и его ID вне репозитория, документов и чата. Не проси пользователя присылать ключ сообщением; используй безопасное локальное хранилище и отзывай ключ при подозрении на утечку.

Сначала открывай только файлы, относящиеся к задаче. Не сканируй весь проект для общего знакомства.

## Ограничения при изучении проекта

- Не открывай PDF, снимки экрана, `app/build/`, `.dart_tool/` и сгенерированные файлы локализации, если задача прямо этого не требует.
- Файл `app/lib/data/quiz_questions.dart` читай только при работе с вопросами.
- Не читай все экраны подряд; используй поиск и точечное чтение.
- Не просматривай файлы секретов и не копируй секреты в исходники или документы.

## Подтверждённое поведение локального прототипа

- При первом запуске перед вводом имён показывается английский онбординг из трёх страниц. Skip и Get started сохраняют `onboarding_done`; повторный запуск продолжает настройку или открывает главную. Для уже настроенной игры онбординг пропускается. Повторный просмотр: Settings → Replay intro.
- Для начала игры нужны отображаемое имя или ник и не менее трёх имён участников (`LocalGameService.minFriends`). Логин и регистрация не требуются. Кнопка Try with example names доступна всем и запускает обычную игру с примерами; реальные имена не обязательны.
- Имена используются как подписи карточек викторины. Это не аккаунты пользователей; уведомления им не отправляются.
- Share Flyprox отправляет короткий английский текст без сайта и реферальной ссылки. Instagram копирует сообщение и открывает приложение для вставки. На экране отправки оставлены только WhatsApp и Instagram; названия показаны текстом без логотипов.
- Игровой раунд состоит из 12 вопросов, после него начисляются звёзды и запускается таймер на 40 минут. Нажатие WhatsApp или Instagram на экране Share Flyprox снимает текущий таймер независимо от отправки сообщения и наличия внешнего приложения; отправка добровольная. Экран таймера читает сохранённое время, включая возврат из отправки и перезапуск. После завершения 12 вопросов на экране награды доступна одна кнопка Reveal: показывает только собственные локальные ответы за последний завершённый раунд, включая пропуски. Входящих голосов других людей нет. Текущие ответы и прогресс сохраняются между запусками во всех раундах; предыдущий завершённый раунд заменяется новым.
- Профиль берёт данные из `LocalGameService`; университет и курс хранятся локально. Университет выбирается через поиск по локальному справочнику NCES/IPEDS HD2024: 3980 активных учреждений США, выдающих степени (2- и 4-летние, включая DC и территории США). Источник и критерии указаны в `app/assets/data/us_universities.json`, обновление: `app/tool/update_us_universities.py`. Выбор необязателен; старые введённые значения сохраняются до замены или очистки.
- Текущий релиз бесплатный: предложения Premium, подписки, платное раскрытие имён и значки платного статуса убраны из доступного интерфейса. Старые URL `/premium` и `/premium-result` перенаправляют на главную; экраны покупок не подключены к роутеру.
- Основная локальная навигация: четыре вкладки — главная, игра, профиль и настройки. Шестерёнка перенесена из профиля в четвёртую вкладку; связанные страницы помощи и приватности выделяют настройки. Кнопка игры и прямые переходы к опросу проверяют сохранённый таймер: до окончания или сброса открывается тот же оставшийся таймер, без генерации нового раунда.
- Политика конфиденциальности и условия хранятся на отдельных страницах Notion; Settings открывает ссылки из `AppConstants`, веб-страницы privacy.html/terms.html перенаправляют туда же. Страницы Notion должны быть опубликованы через Share → Publish для доступа без аккаунта.

Эти сведения описывают локальный прототип и могут устареть. Перед изменением поведения сверяй их с кодом; при обнаружении расхождения сначала исправь документацию.

## Запуск и проверка интерфейса

Для локального запуска используй Google Chrome:

```bash
cd app
flutter pub get
flutter run -d chrome
```

Не используй Xcode, iOS Simulator или `flutter run -d macos`, если пользователь прямо этого не попросил. Запускай проверки только когда это нужно для задачи или пользователь попросил проверить изменения.

## Правила изменений и Git

- Перед правками проверь `git status` и не перезаписывай чужие изменения.
- Делай узкие, связанные с задачей изменения. Не добавляй зависимости и документацию «на всякий случай».
- Не добавляй токены, `.env`, PAT, учётные данные или секреты MCP в Git.
- Значимые изменения по правилам репозитория нужно фиксировать отдельным коммитом и отправлять в `main` репозитория `amanvelikiigmailcom/poll-main`.
- Не делай force-push. Перед отправкой изменений во внешний репозиторий получи явное подтверждение пользователя.

## Документация

`AGENTS.md` — единственный источник актуальных инструкций проекта. `CLAUDE.md` содержит только ссылку на него. Исторические аудиты с датой не считать описанием текущего состояния; подтверждай актуальность по коду.

## Подтверждённые изменения текущего релиза

- Reset game из Settings, Edit profile и совместимого /delete-account использует единое подтверждение. Удаляет локальные игровые поля и сбрасывает кэши профиля; обязательной причины нет. Log out отсутствует, поскольку серверных аккаунтов нет.
- Report a question готовит письмо с ID и текстом текущего вопроса, не включает имена участников и ответы. Пользователь сам открывает почту или копирует текст; автоматической отправки нет.
- Позиционирование в интерфейсе и метаданных: name-based quiz game. Не обещать социальную сеть, входящие голоса, шифрование SharedPreferences или неподтверждённое соблюдение GDPR/COPPA.
- Логотип: app/assets/images/flyprox-logo.png; из него подготовлены нативные и веб-иконки. При добавлении новых assets в pubspec полностью перезапускать flutter run и проверять адрес ресурса Flutter (/assets/assets/...), одного hot restart недостаточно.

- Firebase Core, Analytics и Messaging удалены из зависимостей и инициализации. Локальная игра не использует Firebase; запрос разрешения push-уведомлений при запуске удалён.

- Эффекты: Settings → Sound, Haptics, Reduce motion; выбор сохраняется отдельно от игровых данных. Reduce motion также учитывает настройку устройства; упрощает заставку, переходы голосования, награду и таймер.
- Необязательный аватар сохраняется локально как уменьшенный PNG без исходных метаданных (до 512 КБ), доступен в профиле и редактировании. Remove photo применяется при Save; Reset game удаляет сохранённый аватар и ответы. Оригинал в фототеке не изменяется.
- Settings → View my local data показывает JSON локального профиля, аватара и ответов; Copy JSON копирует его только по нажатию пользователя. Не считать эту функцию подтверждением соблюдения GDPR.
- Видеозаставка включена: `app/assets/animations/flyprox-intro.mp4`, 4 секунды, 1080×1920, H.264/30 fps, музыка AAC внутри MP4. Если ролик отсутствует или не воспроизводится, показывается логотип и запуск продолжается. Есть Skip, отключение звука и ограничение ожидания; в Chrome видео запускается без звука из-за ограничений autoplay. После добавления файла полностью перезапустить Flutter. Параметры и промпт: `docs/intro-video.md`.
- Подготовленные изменения опубликованной политики: `docs/privacy-policy-update.md`. Это проект дополнений; публикация в Notion требует отдельного подтверждения. Поставщики поддержки, сроки хранения, правовые основания и применимость GDPR требуют отдельной проверки владельцем приложения.

- Исходные PPM-материалы дизайна (146 файлов, ~151 МиБ) хранятся в `design-reference/ppm/`, вне `app/assets/`, и не входят в ресурсы Flutter. Не добавлять эту папку в `pubspec.yaml`.
