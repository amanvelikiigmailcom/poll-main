## 3. Что можем сделать / что нет — обсуждаем, не правим

### Группа A — Можно за 5 мин (экран готов, надо только добавить `GoRoute`)
16 маршрутов, риск минимальный, Playwright станет 37/37 зелёных:
`faq`, `for-parents`, `collection`, `friends`, `friend-requests`, `likes*`, `room`, `create-room`, `activity`, `search`, `notifications-settings`, `blocked-users`, `hidden-users`, `settings-poll` (+ `language-settings` если решим выносить диалог в отдельный экран).

### Группа B — Сознательно отключены (не трогать без решения)
В `app_router.dart` коммент: `// Kept so leftover screens still compile. Not registered`:
`onboarding`, `phone`, `otp`, `register`, `location`, `school`, `classSelect`, `username`, `contacts`, `photo`, `before-vote`, `before-vote-2`, `star-taking`.
Они требуют Firebase Auth / API (`api_service`, `auth_service`, `poll_service`) и бэк. Сейчас приложение работает локально через `LocalGameService` (SharedPreferences) без сервера. Если зарегать — будут висеть лоадеры.

### Группа C — Спорные, нужно твоё решение
- **`/premium`** — UI готов, `in_app_purchase` уже в `pubspec`, но покупки требуют StoreKit/Play + валидацию на бэке. Вариант: зарегать как статичный экран-заглушку (тарифы без оплаты) или оставить редирект.
- **`/profile/:id`** — `GoRoute(path: '/profile/:id')` + `profile_for_people_screen` — 10 строк, но без API будет пусто. Делать мок-данные или скрыть кнопки `push(/profile/${id})`?
- **`/language-settings`** — сейчас это диалог внутри `SettingsScreen`, отдельный экран дублирует. Оставляем диалог или выносим?

### Предложенные варианты
- **Вариант A (быстрый win):** Включить всю Группу A — все кнопки в `Profile/Menu/Settings` перестанут тихо уводить на `/names`.
- **Вариант B (минимальный):** Только `premium`, `collection`, `faq`, `for-parents` — видимое в меню.
- **Вариант C (ничего не регать):** Заменить `push` на `SnackBar("Скоро")` — честный UX без молчаливого редиректа.

**Решение пока не принято — ждём твоего выбора. Файл зафиксировал состояние на 2026-09-03.**

## 4. Как воспроизвести проверку локально

```bash
cd app
flutter build web --no-pub
node /tmp/spa-server.js &  # или npx serve -s build/web -l 8082
# в другом терминале:
cd /tmp/poll-playwright && npx playwright test --reporter=list
# скриншоты: /tmp/poll-playwright/screenshots*.png
```

По `AGENTS.md` дефолт для просмотра — `flutter run -d chrome` (Chrome, не симулятор). Для публикации — `flutter build web` + хостинг `build/web`.
